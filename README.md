# NB2420 logbooks (archived)

The logbooks have moved to the course book:
**https://nb-tudelft.github.io/Electronic_Instrumentation/miscellaneous/logbooks.html**

The editor is now part of
[sphinx-typst-render](https://github.com/NB-TUDelft/sphinx-typst-render), and
the logbooks are written in the
[course book](https://github.com/NB-TUDelft/Electronic_Instrumentation)
(`book/manuals/weekN/`). Make any change to the logbooks or the editor there.

This repo is read-only. Its site (https://nb-tudelft.github.io/EI_Logbooks/)
stays up and sends every visitor, old logbook links included, to the page
above. Students' saved work carries over, because both sites run on the same
address and use the same browser storage.

## What is still here

| Folder | What |
|--------|------|
| [`site/`](site/) | the old site; its start page and editor now redirect |
| [`templates/`](templates/) | the logbooks as they were at the move |
| [`tools/`](tools/) | `logbooks_to_dataframe.py` reads handed-in logbooks into one table; the rest are the old build scripts |
